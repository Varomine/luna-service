## 📱 How to Import into Luna App

1. Open **Luna** app on iOS / iPadOS.
2. Go to **Settings** $\rightarrow$ **Modules** $\rightarrow$ **Add / Import Module**.
3. Copy and paste any of the **Manifest JSON URLs** listed above.
4. Tap **Import & Save**.
